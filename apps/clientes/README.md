# Módulo de Clientes

Este módulo será responsável pelo cadastro e gerenciamento dos clientes da Bravon Express.

## Informações previstas

- Nome do cliente;
- Telefone para contato (opcional);
- Frequência de fechamento: semanal, quinzenal ou avulso;
- Data de cadastro;
- Situação do cadastro: ativo ou inativo.

## Objetivo

Organizar os dados dos clientes e facilitar o controle dos serviços e pagamentos vinculados a cada um.
