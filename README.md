# Bravon Express — Sistema de Controle de Entregas

## Sobre o projeto

O Bravon Express — Sistema de Controle de Entregas é um MVP desenvolvido para auxiliar o setor administrativo da Bravon Express no registro e acompanhamento dos serviços realizados e dos pagamentos dos clientes.

O projeto surgiu a partir da identificação de uma dificuldade no processo atual: os serviços são registrados manualmente em uma planilha do Excel, enquanto o controle de pagamentos pendentes é realizado separadamente em anotações. Essa organização aumenta o trabalho manual e dificulta a consulta das informações.

## Objetivo

Centralizar as principais informações administrativas em um único sistema, facilitando o registro das corridas, o acompanhamento dos pagamentos e a identificação de valores pendentes.

## Funcionalidades previstas

- Cadastro de clientes;
- Definição da frequência de fechamento do cliente;
- Registro de corridas realizadas;
- Registro de pagamentos;
- Consulta de corridas pagas e pendentes;
- Consulta do histórico por cliente e período;
- Visualização dos valores em aberto.

## Público-alvo

O sistema será utilizado principalmente pelo responsável pelo setor administrativo da Bravon Express.

## MVP

O MVP será desenvolvido como uma aplicação web acessível pelo navegador. A primeira versão terá como foco o cadastro de clientes, registro de corridas e controle de pagamentos e pendências.

## Tecnologias previstas

- Python
- Django
- HTML5
- CSS3
- Bootstrap
- PostgreSQL

## Arquitetura

O sistema utilizará uma arquitetura monolítica em camadas, organizando a aplicação em:

- **Apresentação:** telas e interação com o usuário;
- **Lógica de aplicação:** regras de negócio e validações;
- **Persistência de dados:** armazenamento e consulta das informações no banco de dados.
